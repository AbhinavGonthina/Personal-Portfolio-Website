# Unfinished prototype — botanical redesign

A hand-drawn, cream-and-camel direction for the portfolio: a portrait set into
a line-art brick wall with a dart easter egg, falling leaves and a moss
backdrop behind the sections, deep-pine domain cards for skills, and an ending
screen of four hands reaching up out of the ground to offer a résumé, an
envelope and two cards.

**Abandoned part-way**, in favour of a dark, modern, technical direction. It is
kept here, buildable and viewable at `/prototype/`, because a screenshot in a
commit message is not the same as being able to click the thing.

Not maintained. It carries its own `package.json` and `node_modules`, pinned
to the MUI + Emotion stack the main app no longer uses.
